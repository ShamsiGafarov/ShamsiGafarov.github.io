# BrewHaven ☕

> A full stack coffee ordering platform built with the MERN stack.

## Overview
BrewHaven is a full-featured coffee ordering web application demonstrating end-to-end full stack development. Users can browse products, manage a cart, authenticate, and place orders — all backed by a RESTful Node.js/Express API and MongoDB database.

## Features
- Product browsing with category filtering
- Shopping cart with real-time quantity management
- User authentication (register/login/logout)
- Order processing and order history
- Fully responsive design

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | React, JavaScript, CSS3 |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| Auth | JWT Authentication |
| Architecture | RESTful API, MVC Pattern |

## Getting Started
```bash
git clone https://github.com/ShamsiGafarov/BrewHaven.git
cd BrewHaven
npm install
npm run dev
```
