# Portfolio Platform

> A decoupled portfolio web application with a dedicated frontend and backend API.

## Overview
A professionally structured portfolio application demonstrating clean separation of concerns between frontend and backend. The frontend handles all UI rendering while the backend provides a RESTful API layer — a pattern common in production-grade web applications.

## Features
- Decoupled frontend/backend architecture
- RESTful API design
- Dynamic content rendering from API responses
- Clean, responsive UI

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Frontend | JavaScript, HTML5, CSS3 |
| Backend | Node.js, Express.js |
| Architecture | REST API, Separation of Concerns |
